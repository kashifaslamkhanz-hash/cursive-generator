# Flourish Cursive Generator

Static HTML, CSS, and JavaScript website for GitHub Pages. Open `index.html` to use the Phase 1 studio. Phase 2 route folders provide generator guides and supporting pages; `blog/` contains three articles.

## Deploy

Publish this folder with GitHub Pages. Replace `YOUR-DOMAIN.example` in `robots.txt`, `sitemap.xml`, and canonical metadata before production. Google Fonts are loaded from Google Fonts; their individual licence information must be retained/verified if self-hosting them later.

## Manual checklist

- Try text, each font, colour, background, alignment, copy, PNG, and SVG on the home page.
- Open each route and check its links.
- Test narrow-screen layout in browser responsive mode.
- Confirm the contact placeholder has been replaced before publishing.
